# Security Policy

## Reporting a vulnerability

If you discover a security issue, please report it privately instead of filing a public issue.

Create a private advisory on GitHub under "Security > Report a vulnerability", or contact the maintainer via <https://arunneupane.vercel.app>.

## Scope

This project stores only local data (game settings, statistics, and in-progress runs) in browser storage. No accounts, no server-side persistence, no tracking.

## Response

We aim to acknowledge reports within 5 business days and address confirmed issues in a timely release.
